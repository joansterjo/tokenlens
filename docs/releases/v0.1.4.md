# TokenLens 0.1.4 — Version and package refresh

Built by [Joan Sterjo](https://github.com/joansterjo).

This release refreshes version metadata, downloads and documentation under 0.1.4. It carries forward the fixes from 0.1.3 with no new runtime behavior changes.

## Included

- Current release version across the extension, CSS export header, download filenames, product page and installation instructions.
- Rebuilt standard and per-site permissions packages, with updated SHA-256 checksums.
- The existing fix for valid CSS colors with missing components, including `oklch(0.5 none none)`.
- The existing editor recovery screen with retry, JSON and CSS backup, plus guarded theme preference storage.

Validation for 0.1.4: 93 Node tests, 84 browser tests and 16 extension/platform/performance tests passed. Typecheck, lint, both production builds, bundle-size budgets and release consistency checks passed. See the [verification report](https://github.com/joansterjo/tokenlens/blob/main/docs/verification.md) for evidence and remaining manual checks.

## Download and install

- [tokenlens-0.1.4.zip](https://github.com/joansterjo/tokenlens/releases/download/v0.1.4/tokenlens-0.1.4.zip) — standard build with access to supported pages.
- [tokenlens-0.1.4-optional-permissions.zip](https://github.com/joansterjo/tokenlens/releases/download/v0.1.4/tokenlens-0.1.4-optional-permissions.zip) — connect sites individually from the toolbar popup.
- [SHA256SUMS](https://github.com/joansterjo/tokenlens/releases/download/v0.1.4/SHA256SUMS) — checksums for both ZIP files.

For a new installation, extract one ZIP, open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the extracted folder containing `manifest.json`. Reload the website, open DevTools and choose **Tokens** from the tab bar or **»** menu. With the per-site build, connect the site through the toolbar popup first.

The popup connects the page; the editor lives in **DevTools → Tokens**. Connecting does not open DevTools automatically. Both ZIPs include `INSTALL.txt`.

## Update an existing installation

Unpacked extensions do not update automatically. Install only one build at a time.

1. Save edits you want to keep before updating. If the recovery screen is available, use **Save session JSON** or **Save CSS** there.
2. Download the same build you already use, extract it, and replace the contents of your existing extension folder. Keep its folder path unchanged.
3. Click TokenLens's **Reload** button in `chrome://extensions`.
4. Reload the website and close/reopen DevTools. Confirm **v0.1.4** in the popup footer, then choose **Tokens**. Reconnect the site if prompted.

## Limits

This release retains the scope and limitations of 0.1.3. The missing-component crash has a confirmed reproduction; the original reported private page's error stack has not been observed, so this is not confirmation that every blank-panel cause is resolved. Editor recovery preserves existing session edits after caught rendering errors; save a backup before reloading.

Token provenance and consumer counts remain best-effort. Advanced CSS, unreadable stylesheets and some shadow-root cases can limit attribution or export fidelity. Native optional-permission prompts, docked/undocked EyeDropper behavior and bulk declaration-editor paste still need manual verification.

This is an unpacked extension release, outside the Chrome Web Store. See the [export guide](https://github.com/joansterjo/tokenlens/blob/main/docs/export-targets.md) for preview/export behavior. Previous release: [0.1.3](https://github.com/joansterjo/tokenlens/releases/tag/v0.1.3).
