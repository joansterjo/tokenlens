# TokenLens 0.1.1 — Clear connection and onboarding

Built by [Joan Sterjo](https://github.com/joansterjo).

Connecting a site now leads to a visible readiness state and clear instructions for continuing in **DevTools → Tokens**.

## Fixed

- The popup checks the actual active website each time it opens. It shows the hostname, site-access permission, inspector readiness and installed version.
- Connection success waits for the inspector to load and connect. Missing responses, denied access and protected pages show actionable errors.
- Permission requests run directly from the Connect button's user gesture.
- Onboarding shows where to find Tokens, including the **»** overflow menu and the need to reopen DevTools after installing or updating the extension.
- Opening Tokens picks up the element already selected in Elements. Selection recovery handles a missing inspector and waits for it to become ready.
- Initial pick/resync requests wait for injection; recovered connections clear stale connection errors.
- The Elements sidebar provides guidance to the Tokens tab.
- Source confidence uses clearer labels: **Partial source trace** and **Estimated source trace**, with an explanation that uncertainty concerns the original CSS rule and token attribution.
- Token values and palette colors prefer the browser's computed value over reconstructed alias values when the two disagree. Source details retain the authored value and alias chain.

## Install or update

Download **tokenlens-0.1.1.zip** (standard) or **tokenlens-0.1.1-optional-permissions.zip** (connect sites individually). Install only one build.

For a new installation, extract the ZIP, open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the extracted folder containing `manifest.json`.

To update an existing unpacked installation, extract the same build into your existing extension folder and click TokenLens's **Reload** button in `chrome://extensions`. Reload the website and close/reopen DevTools. Check **v0.1.1** in the popup footer.

Once the popup says **Connected**, close it, open DevTools, and choose **Tokens**. The editor lives in that tab; the popup handles connection and setup.

Both downloads include `INSTALL.txt`. **SHA256SUMS** contains their checksums. This is an unpacked extension release, outside the Chrome Web Store.

The [verification report](https://github.com/joansterjo/tokenlens/blob/main/docs/verification.md) describes automated checks and remaining manual coverage, including Chrome's native permission prompt.
